# Fichiers d'intégration des auteurs de contenus

Chaque auteur (agent) écrit ici `<clé>.json` : la liste des chapitres qu'il a rédigés, pour que le
coordinateur les rattache aux parcours (`app/content/courses/`) sans conflit d'écriture.

```json
[
  { "course": "maths-5e", "chapter": "m5-ch-symetries", "lessons": ["m5-symetries"], "skills": ["m5.geo.symetrie-axiale"] }
]
```
